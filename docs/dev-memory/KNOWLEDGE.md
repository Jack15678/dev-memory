## K-001 · 2026-10-03 · 结束事件不能代替任务验收

- 成熟度：本项目已验证协议层行为；宿主自动触发效果尚待实际启用后观察。
- 发现：回合结束只说明 agent 准备停止响应，无法证明用户目标已经完成。可以用事件触发一次检查，但内容取舍和提交条件仍需结合用户目标、代码变化与验证结果判断。
- 适用边界：具有生命周期 Hook 的 agent 工作流；具体事件字段和防循环办法依宿主而异，不能直接复制协议到其他工具。
- 证据：本项目 `tests/test_dev_memory.py` 验证 Stop 检查不会写入文件、回执和 `stop_hook_active` 会放行；独立任务试用由 agent 运行边界检查后提交代码与记录。
- 在本项目的应用见 [D-003](DECISIONS.md#d-003)。
